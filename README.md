Codesk — Coding Portfolio Management

Version: Beta v0.1
Status: 🚧 In Development
Project Type: Coding Portfolio Management System

Codesk is a coding portfolio management project designed to bring coding activities, projects, and development resources together in one place. It aims to provide both a Command-Line User Interface (CUI) and a Graphical User Interface (GUI), giving users the flexibility to interact with the system through their preferred workflow.

The goal of Codesk is to create a unified, organized, and accessible environment for managing a coding portfolio.

✨ Overview

Managing multiple coding projects can become difficult as the number of repositories, files, and development activities grows. Codesk aims to simplify this process by providing a centralized platform for organizing and managing coding-related work.

With support for both CUI and GUI interfaces, Codesk is intended to accommodate users who prefer terminal-based workflows as well as those who prefer a visual interface.

🎯 Objectives
Centralized Management: Organize coding projects and portfolio-related resources in one place.
Dual Interface Support: Provide both CUI and GUI experiences.
Improved Organization: Make coding projects easier to manage and navigate.
Workflow Flexibility: Support different user preferences and working styles.
Future Extensibility: Establish a foundation for additional portfolio management features.
🖥️ Interfaces
1. CUI — Command-Line User Interface

The CUI is intended for users who prefer interacting with applications through a terminal.

Potential capabilities include:

Managing coding portfolio entries through commands.
Navigating and interacting with project information.
Performing supported operations without a graphical interface.
2. GUI — Graphical User Interface

The GUI is intended to provide a visual and user-friendly way to interact with Codesk.

Potential capabilities include:

Viewing and navigating portfolio information visually.
Managing coding projects through graphical controls.
Accessing supported features without relying on terminal commands.
Note: The exact capabilities of each interface depend on the current implementation. Features listed as potential capabilities should be considered planned until implemented.
